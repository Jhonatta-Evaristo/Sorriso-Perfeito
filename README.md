## 🦷 Clínica Odontológica - Landing Page

Este projeto é uma landing page moderna desenvolvida para uma clínica odontológica, com foco em apresentação institucional, captação de pacientes e agendamento de avaliações.

O site foi construído com **HTML, TailwindCSS e JavaScript**, utilizando animações suaves e layout totalmente responsivo para oferecer uma experiência agradável em qualquer dispositivo.

Entre os recursos presentes no projeto estão:

- Design moderno e responsivo
- Animações ao rolar a página (AOS)
- Seção de serviços interativa
- Apresentação da equipe médica
- Depoimentos de pacientes
- Galeria da clínica
- Formulário de agendamento de avaliação
- Integração com botão flutuante do WhatsApp
- Botão de retorno ao topo

O objetivo do projeto é simular um site real de clínica odontológica, podendo ser utilizado como **modelo para projetos freelancers ou portfólio de desenvolvimento web**.
